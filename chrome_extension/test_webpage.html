🧪 AI Data Cleaner - Test Playground

This page contains sample datasets with common real-world data problems (nulls, duplicates, inconsistent casing, currency formatting). Click the extension icon in your Chrome toolbar to test table detection, profiling, and 1-click cleaning!

🚀 How to Load & Test across Browsers:

🌐 Microsoft Edge:
  1. Navigate to edge://extensions/
  2. Turn on "Developer mode" in the left sidebar.
  3. Click "Load unpacked" and select the chrome_extension folder.
🦊 Mozilla Firefox:
  1. Navigate to about:debugging#/runtime/this-firefox
  2. Click "Load Temporary Add-on..."
  3. Select the manifest.json file inside chrome_extension.
🟢 Google Chrome / Brave:
  1. Navigate to chrome://extensions/
  2. Enable "Developer mode" (top-right toggle).
  3. Click "Load unpacked" and choose the chrome_extension folder.

🔒 Privacy Architecture: AI API keys and all data cleaning operate strictly inside your local browser. No keys or dataset records are uploaded to remote servers.
